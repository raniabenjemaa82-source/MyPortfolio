# MyPortfolio – Student Portfolio App

A Flutter mobile application developed as an academic project.

## About the Project

MyPortfolio is designed to present and manage the academic and professional portfolios of two students in a single application.

## Main Features

- View individual student portfolios.
- Display personal and academic information.
- Manage skills and projects (Add, Edit, Delete).
- Store portfolio data locally using SharedPreferences.
- Retrieve external data through a REST API.
- Navigate between student portfolios.

## Technologies Used

- Flutter
- Dart
- REST API
- HTTP
- SharedPreferences

## Installation

1. Clone the repository:
   `git clone https://github.com/raniabenjemaa82-source/MyPortfolio.git`
2. Open the project folder.
3. Install dependencies:
   `flutter pub get`
4. Run the application:
   `flutter run`
